# I Launcher Branding

## Verbindliches App-Icon

Das App-Icon von **I Launcher** ist ab diesem Stand dauerhaft das minimalistische Motiv **„Person als kleines i vor einem Fernseher“**.

Gestaltungsprinzipien:

- dunkelblauer bis navyfarbener Hintergrund
- heller, reduzierter TV-Rahmen
- die Figur bildet gleichzeitig ein kleines `i`: Kopf = Punkt, Körper = Stamm
- keine Beschriftung im Icon
- klare, große Formen für gute Erkennbarkeit auf TV, Smartphone und in Android-Systemdialogen
- keine zusätzlichen Szenen, Fotos oder kleinteiligen Elemente

Die Android-Runtime-Ressource liegt unter:

`app/src/main/res/drawable/ic_launcher.xml`

Die editierbare visuelle Referenz liegt unter:

`docs/branding/i_launcher_app_icon.svg`

Das Manifest referenziert `@drawable/ic_launcher`; dadurch wird das Motiv automatisch in allen zukünftigen APK-Builds verwendet. Das Icon soll nur nach einer ausdrücklichen neuen Branding-Entscheidung ersetzt oder grundlegend verändert werden.
